# Le Weilai KDS demo

一个可以直接在浏览器里体验的餐厅点单、后厨与出菜口演示页面。

## 体验

打开 `public_site/index.html`，或在 `public_site` 目录运行任意静态文件服务器。页面顶部（窄屏时为底部）可切换点单、后厨、出菜口和后台。首屏已放入 T03、T07、T12 三桌样例单，可体验超时颜色、同菜汇总、饮品分流、催菜、退菜提示和划单撤销。语言按钮可在中文与法文间切换。

所有样例和操作数据保存在当前浏览器。相同浏览器里打开多个页面时会同步；不同设备之间还没有云端同步。小票可预览并交给浏览器打印，不会直接连接 Epson 打印机。

## 发布

推送到 GitHub 仓库的 `main` 分支后，`.github/workflows/pages.yml` 会将 `public_site` 发布到 GitHub Pages。需求文档 PDF 不包含在网站发布目录中。

## 页面范围

- 手机点单：桌位图、人数、搜索、分类、中法菜名、库存限制、常用备注、确认发送与小票预览。
- 后厨 KDS：单菜等待时间、超时颜色、断档时间、加菜/催菜/过敏提醒、同菜汇总。
- 出菜口：菜品与饮品分流、逐菜/整桌划单、进度、10 秒撤销。
- 后台：菜单与过敏原、沽清和限量库存、桌位、今日概览、操作日志、超时和显示设置。

真实营业所需的跨设备云同步、员工 PIN、Epson ePOS 自动打印、离线补单和正式权限控制不在此静态演示版内。
